# Fortran version of COMPLY code

```
make -f makefile1
```

Instructions for compiling "Level 2" on a linux system:

```
make -f makefile2
```

Instructions for running "Level 1" on a linux system:

```
./level1
```

Instructions for running "Level 2" on a linux system:

```
./level2
```
